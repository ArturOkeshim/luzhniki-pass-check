# Проверка абонементов «Лужники»: серверный пакет V1

Пакет устанавливает мобильный веб-сервис для охраны. Сервис:

- требует отдельный логин и пароль;
- содержит пять аккаунтов `guard01`…`guard05`;
- сначала проверяет абонемент и штраф в Bitrix;
- если абонемента в Bitrix нет, обязательно проверяет приёмник через защищённый шлюз;
- показывает ГРН, состояние абонемента, даты, тариф, разрешённый период нахождения и предупреждение о штрафе;
- считает даты по часовому поясу Москвы;
- слушает только `127.0.0.1:8788`, наружу публикуется через nginx и HTTPS.

Секретов в архиве нет. `configure.sh` создаёт их непосредственно на сервере и сохраняет с правами `0600`.

## Состав

- `app/` — исходный код приложения;
- `configure.sh` — создаёт серверную конфигурацию и пять случайных паролей;
- `install.sh` — проверяет конфигурацию, собирает приложение, устанавливает systemd-сервис и проверяет его запуск;
- `SERVER-CONFIG.env.example` — полный перечень серверных параметров без секретов;
- `nginx-luzhniki-pass-check.conf.example` — reverse proxy для домена;
- `INSTALL.md` — пошаговая инструкция.

Начните с `INSTALL.md`.
