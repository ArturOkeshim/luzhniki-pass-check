# Проверка парковочных абонементов «Лужники»

Мобильный веб-сервис для охраны с отдельным входом по служебному логину и паролю. Поддерживает до 20 независимых аккаунтов через пары `SERVICE_AUTH_LOGIN_N` / `SERVICE_AUTH_PASSWORD_N`; сессия привязывается к действующему аккаунту. Ищет парковочный абонемент по полному ГРН или его части сначала в Bitrix, а при отсутствии результата — в приёмнике Skidata через защищённый read-only шлюз на сервере Bitrix. Также проверяет наличие неоплаченного штрафа в Bitrix.

Сервис показывает только:

- ГРН;
- даты начала и окончания;
- название тарифа;
- разрешённые дни, часы и максимальную продолжительность посещения.
- состояние абонемента: действует, закончился или ещё не начался;
- заметное предупреждение, если по ГРН есть неоплаченный штраф.

Состояние проверяется по календарной дате сервера в часовом поясе `Europe/Moscow`; обе границы периода включены. Тестовый товар Bitrix исключён. Если Bitrix не вернул абонемент, проверка в приёмнике обязательна. Только подтверждённое отсутствие в обоих источниках даёт результат «ГРН не найден». Если приёмник недоступен, сервис сообщает о технической ошибке и не показывает ложное отсутствие.

## Локальный запуск

Требуется Node.js 22.13+ и pnpm.

```powershell
Copy-Item .env.example .env.local
pnpm install
pnpm dev
```

Заполните в `.env.local` реальный вебхук Bitrix, служебный логин/пароль, секрет сессии и токен шлюза приёмника. Эти значения используются только серверной частью и не передаются в браузер. Пароль должен содержать не менее 12 символов, секрет сессии — не менее 32. По умолчанию приложение открывается на `http://127.0.0.1:5173/`.

Рабочая схема при размещении вне внутренней сети:

```text
браузер охраны → сервис проверки → сервер Bitrix → приёмник Skidata
```

Read-only шлюз находится в соседнем пакете `deliverables/PARKING-SUBSCRIPTION-CHECK-GATEWAY-V1`. Он не использует авторизацию пользователя Bitrix, не меняет данные и принимает только запросы с отдельным серверным токеном.

Для локальной разработки можно использовать соседний локальный интерфейс приёмника с `RECEIVER_SIDECAR_URL=http://127.0.0.1:8765/api/state`, но только когда он действительно подключён и возвращает `mode: live`. Демоданные не принимаются.

Авторизации через ChatGPT в проекте нет.
